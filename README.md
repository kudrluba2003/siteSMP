## ✉️ Как подключить сайт к домену smp-nn.ru и НЕ СЛОМАТЬ ПОЧТУ

Главное правило: **не меняйте NS-серверы** домена у регистратора.

В панели управления DNS (где делегирован домен — Reg.ru, Beget, Nic.ru и др.):
1. **НЕ ТРОГАЙТЕ** записи типа `MX` (они отвечают за доставку почты на текущие ящики).
2. **НЕ ТРОГАЙТЕ** записи типа `TXT` (SPF, DKIM, DMARC), чтобы письма не попадали в спам.
3. **ИЗМЕНИТЕ ТОЛЬКО A-записи сайта**:
   * Для домена `@` (или `smp-nn.ru`): `A` -> IP-адрес нового хостинга.
   * Для поддомена `www`: `CNAME` -> `smp-nn.ru.`
